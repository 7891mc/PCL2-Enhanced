FAQ

常见问题

为什么有些模组搜不到？

开源版未内置 CurseForge API Key，CurseForge 请求自动降级；Modrinth 源免 key 完全可用，仅 CurseForge 独占内容缺失。

如何启用 CurseForge 源？

无需改代码：设置环境变量 PCL_CURSEFORGE_API_KEY 后重启 PCL2 即可。Key 通过 CurseForge 官方申请表获取。

和官方版有什么区别？

基于官方 2.99.0.0 源码：修复下载限制 + 21 项功能增强。界面动效、交互风格与官方版完全一致。

如何从源码编译？

Windows + .NET Framework 4.8 Developer Pack + VS2022，Release/x64 编译，详见上方编译指南与 build-notes.md。
